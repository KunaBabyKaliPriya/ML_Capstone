# Clustering — Machine Learning Capstone

## Overview
This track focuses on discovering patterns and natural groupings in unlabeled data using unsupervised machine learning algorithms. It includes data exploration, preprocessing, clustering, evaluation, and visualization.

## Workflow
1. Dataset loading and EDA
2. Data cleaning and preprocessing
3. Feature scaling, where appropriate
4. Clustering algorithm implementation
5. Cluster selection and evaluation
6. Dimensionality reduction and visualization
7. Algorithm comparison and interpretation

## Evaluation Metrics
- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Index

## Visualizations
- Elbow Curve for K-Means
- Dendrogram for Hierarchical Clustering
- PCA-based 2D scatter plots
- t-SNE visualization, where applicable

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

## How to Run
1. Open the clustering notebook.
2. Install the required Python libraries.
3. Ensure the dataset path is correct.
4. Execute all cells sequentially to view cluster assignments, evaluation metrics, and visualizations.

## Results
The clustering algorithms are evaluated and compared using internal validation metrics and visualizations to understand the quality and structure of the identified clusters.
