# Machine Learning Capstone Project

## Overview
This project covers three major areas of Machine Learning: **Regression, Classification, and Clustering**. It demonstrates the end-to-end ML workflow, including Exploratory Data Analysis (EDA), data preprocessing, feature engineering, model training, evaluation, comparison, and hyperparameter tuning.

## Project Structure

```text
ML_Capstone/
├── Regression/
├── Classification/
├── Clustering/
└── README.md
```

## Project Tracks

### 1. Regression
Predicts continuous numerical values using regression algorithms.

**Evaluation Metrics:** MAE, MSE, RMSE, and R².

### 2. Classification
Predicts categorical labels using classification algorithms and compares their performance.

**Evaluation Metrics:** Accuracy, Precision, Recall, F1-score, and ROC-AUC.

### 3. Clustering
Identifies natural groups and patterns in unlabeled data using unsupervised learning algorithms.

**Evaluation Metrics:** Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz Index.

**Visualizations:** Elbow Curve, dendrogram, PCA, and t-SNE, where applicable.

## Methodology
1. Data loading and understanding
2. Exploratory Data Analysis (EDA)
3. Data cleaning and preprocessing
4. Feature engineering and selection
5. Training and testing data split
6. Model implementation and comparison
7. Hyperparameter tuning
8. Evaluation and visualization
9. Final model selection

## Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Jupyter Notebook

## Installation and Execution

Clone the repository:

```bash
git clone https://github.com/KunaBabyKaliPriya/ML_Capstone.git
cd ML_Capstone
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Open Jupyter Notebook, navigate to the required project folder, and execute the notebook cells sequentially.

The models are evaluated and compared using appropriate metrics for each track. The best-performing models are selected based on the experimental results and the objectives of each task.
